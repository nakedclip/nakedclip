# Nakedclip — تحميل فيديوهات TikTok بدون علامة مائية

مشروع مجاني بالكامل مبني بـ Next.js. الفرونت اند والباك اند في نفس المشروع.

## إزاي تشغّله على جهازك

1. لازم يكون عندك Node.js متثبت (نسخة 18 أو أحدث). حمّله مجانًا من: https://nodejs.org
2. افتح Terminal / cmd في فولدر المشروع وشغّل:
   ```
   npm install
   npm run dev
   ```
3. افتح المتصفح على: http://localhost:3000

## إزاي تنشره مجانًا على Cloudflare (الخيار المُفضّل - باندويدث غير محدود)

المشروع فيه API route شغال على السيرفر، فلازم يترفع على **Cloudflare Workers** (مش Cloudflare Pages العادي، لأن أداة next-on-pages القديمة بقت متلغاة). الطريقة الرسمية دلوقتي هي عن طريق OpenNext adapter:

1. اعمل حساب مجاني على https://dash.cloudflare.com
2. في فولدر المشروع، شغّل:
   ```
   npm install
   npx wrangler login
   ```
   هيفتحلك المتصفح عشان تربط حسابك.
3. بعد كده شغّل:
   ```
   npx wrangler deploy
   ```
   Wrangler هيكتشف إنه مشروع Next.js أوتوماتيك، يظبط الإعدادات، ويرفع الموقع.
4. هتاخد رابط زي: `nakedclip.your-subdomain.workers.dev` — موقعك شغال فورًا مجانًا.

**ملاحظة:** لو حصلت مشكلة في الخطوة دي (بعض إصدارات Next.js محتاجة إعداد يدوي إضافي عبر `@opennextjs/cloudflare`)، قول لكلود يظبطها لك خطوة بخطوة، أو استخدم Claude Code عشان يشغّل الأوامر ويحل أي error يظهر فورًا.

الخطة المجانية من Cloudflare بتديك: طلبات غير محدودة، باندويدث غير محدود، و500 عملية نشر (build) شهريًا — أسخى بكتير من غيرها.

## إزاي تنشره مجانًا على الإنترنت (Vercel) — بديل أبسط

1. اعمل حساب مجاني على https://vercel.com (تقدر تسجل بحساب GitHub بتاعك).
2. ارفع المشروع على GitHub (اعمل repo جديد وارفع الملفات).
3. في Vercel، اضغط "Add New Project" واختار الـ repo بتاعك.
4. Vercel هيتعرف على إنه مشروع Next.js أوتوماتيك، اضغط Deploy.
5. بعد دقيقة أو اتنين هياخد رابط زي: `your-project.vercel.app` — ده موقعك شغال أونلاين مجانًا.

## إزاي الموقع شغال

- المستخدم بيلصق لينك فيديو تيك توك في الصفحة الرئيسية (`pages/index.js`).
- الفرونت اند بيبعت طلب لـ `pages/api/download.js` (وده كود بيشتغل على السيرفر مش على المتصفح).
- السيرفر بيبعت الطلب لخدمة مجانية اسمها tikwm.com اللي بترجع رابط الفيديو الأصلي بدون علامة مائية.
- المستخدم يضغط على زرار "تحميل" وياخد الفيديو.

## ملاحظات مهمة

- الخدمة اللي بنستخدمها (tikwm) مجانية بس مش رسمية من تيك توك، يعني ممكن تقف أو تتغير من غير سابق إنذار — لو حصل كده، الحل إنك تدور على API بديل بنفس الطريقة (بتاخد اللينك وترجع رابط الفيديو).
- الموقع مخصص للاستخدام الشخصي/التعليمي. لو ناوي تحوّله لمشروع تجاري كبير، يُفضّل تراجع شروط استخدام تيك توك وقوانين حقوق النشر في بلدك.
- تقدر تضيف عليه لاحقًا: حفظ سجل التحميلات، دعم فيديوهات متعددة دفعة واحدة، أو واجهة بلغات تانية.
